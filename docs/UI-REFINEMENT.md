## 数据安全

沿用 `version: 1`、`items` 和原有任务字段，继续使用临时文件加 `File.Replace` / `File.Move`。正式数据目录和设置目录不变。

原实现存在“读取失败显示空列表，关闭时无条件保存”的风险。本轮增加以下保护，没有改用新的存储系统：

- 读取失败、记录无效或格式版本未知时禁用修改，并保留原 JSON 和备份。窗口关闭不写入空列表。
- 设置读取失败时，不通过主题切换覆盖原设置。
- 新空列表显示“尚无待办，添加后自动保存”；只在有效文件已读取或写入成功后显示“数据已保存到本机”。
- 写入失败后显示错误，内存更改保留；关闭时重试，仍失败则取消关闭。
- 关闭没有修改的清单不重写文件。
- 切换目录保留原有确认及备份机制，不再提前删除目标文件；切换失败时恢复原目录和状态。
